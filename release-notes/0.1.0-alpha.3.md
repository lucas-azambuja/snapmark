Fourth alpha: copy the text from any part of the screen.

## What's new
- **Copy Text (OCR).** Select an area and click **Copy Text** in the Screenshot group of the action bar, or press **⌘⇧C**. The text goes straight to the clipboard and a floating thumbnail confirms it (with a word count).
  - Runs on your Mac with macOS's own text recognition: no network, automatic language detection.
  - Keeps the reading order. Text on the same row, like table cells, is separated by tabs, so it pastes into spreadsheets as columns.
  - Works with the screenshot timer too.

## Install
1. Download `Snapmark-0.1.0-alpha.3.zip`, unzip it, and move `Snapmark.app` to `/Applications`.
2. The app isn't signed with an Apple certificate, so macOS blocks the first launch. Try to open it once and click **Open Anyway** in System Settings → Privacy & Security, or run:
   ```bash
   xattr -d com.apple.quarantine /Applications/Snapmark.app
   ```
3. Allow Screen Recording when Snapmark asks.

Requires macOS 13 or later. Universal binary (Apple silicon and Intel).
