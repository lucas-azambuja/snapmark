Bug-fix beta.

## Fixed
- **The menu bar icon stayed red after a recording.** Stopping or discarding a recording brought the menu back but left the red recording icon in the menu bar until Snapmark was reopened. It now goes back to the normal icon as soon as the recording ends.

## Install
1. Download `Snapmark-0.1.0-beta.2.zip`, unzip it, and move `Snapmark.app` to `/Applications` (replace the old one).
2. The app isn't signed with an Apple certificate, so macOS blocks the first launch. Click **Open Anyway** in System Settings → Privacy & Security, or run:
   ```bash
   xattr -d com.apple.quarantine /Applications/Snapmark.app
   ```
3. Allow Screen Recording when Snapmark asks (if it already looks enabled, remove it with – and add it again).

Found a bug? Please [open an issue](https://github.com/lucas-azambuja/snapmark/issues).

Requires macOS 13 or later (the loupe and snapping need macOS 14, the microphone needs macOS 15). Universal binary (Apple silicon and Intel).
