Second alpha. Snapmark now has a redesigned editor, editable annotations, and a nicer capture flow.

## What's new
- **Editable annotations.** New Select tool (V): move, resize with handles, change color or stroke, double-click text to edit it, and delete with ⌫ or the trash button. Arrow keys nudge the selection.
- **Redesigned editor** on a translucent dark window: colors and tools on the left, stroke previews on the right, Save and Copy at the bottom.
- **Custom area selection** with screen dimming, a crosshair, and a loupe that shows the pixels, coordinates and hex color under the cursor (macOS 14+).
- **Floating thumbnail** after copying or saving: drag it into any app, or click it to reopen the image in the editor.
- Short animations when the overlay opens, when the area is captured, and when the editor appears.
- **Screen Recording permission screen** with step-by-step instructions and a button that opens System Settings.
- New app and menu bar icons. The app icon stays magenta when macOS uses dark icons.
- *About Snapmark* and the version/build number in the menu.
- English interface.
- Undo/redo now covers every change, including moves and edits.

## Install
1. Download `Snapmark-0.1.0-alpha.1.zip`, unzip it, and move `Snapmark.app` to `/Applications`.
2. The app isn't signed with an Apple certificate, so macOS blocks the first launch. Try to open it once and click **Open Anyway** in System Settings → Privacy & Security, or run:
   ```bash
   xattr -d com.apple.quarantine /Applications/Snapmark.app
   ```
3. Turn off the macOS ⌘⇧5 shortcut and allow Screen Recording when Snapmark asks (details in the README).

## Notes
- The app's identifier changed to `dev.lucasazambuja.snapmark`, so macOS treats it as a new app: you'll need to allow Screen Recording again.
- The shortcut is still fixed to ⌘⇧5.

Requires macOS 13 or later. Universal binary (Apple silicon and Intel).
